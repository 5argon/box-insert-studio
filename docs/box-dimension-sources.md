# Box size research

Researched on 2026-10-01. All values are millimetres, in the app's width × depth × height order. With the cover text upright, width runs left to right and depth runs top to bottom; height is the box thickness. Source dimensions are reordered to match the cover, rather than always putting the longer side first. These are starting points: measure the empty box bottom of your own edition before cutting, and reserve height for boards and rulebooks separately. The app applies its normal tray clearance after selecting a preset.

Eight entries below are explicitly reported as box interiors. Three are **insert-fit references**, clearly marked in the preset name and source hint: they give a usable starting envelope, not a verified measurement of the complete box interior. No publisher exterior dimensions were substituted for interior dimensions.

Several sources block direct page retrieval but expose their descriptions in search results. Measurements were taken from the designers' or owners' explicit descriptions, not model-file bounding boxes. Existing presets were retained; Ark Nova's width and depth were corrected during the cover audit below.
